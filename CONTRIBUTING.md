# Contributing

Start with the [development guide](docs/contributing/README.md).

- Keep pull requests small; describe the changed behavior and how it was verified.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commits and pull request titles.
- Code, comments, and documentation are in English. UI strings live in locale files
  (`en`, `uk`) and are referenced by translation keys.
- Changes to money, authentication, migrations, infrastructure, and CI require code-owner review.

By contributing you agree to license your work under the [project license](LICENSE)
and to follow the [code of conduct](CODE_OF_CONDUCT.md).
