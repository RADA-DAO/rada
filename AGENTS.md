# Repository instructions

- Read `README.md` and the relevant component README before editing.
- Keep changes small and within the requested scope; one logical change per pull request.
- English for code, comments, and documentation; Conventional Commits.
- UI text only in locale files (`en`, `uk`), referenced by translation keys.
- Never commit secrets, personal data, database dumps, or working notes.
- Respect module boundaries: a module never writes to another module's tables.
- Run `npm run check` before opening a pull request and report the result.
